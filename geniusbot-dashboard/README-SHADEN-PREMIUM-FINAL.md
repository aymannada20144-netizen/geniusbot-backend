# Shaden Premium Dashboard — Final UI Review

هذه النسخة هي مراجعة شاملة على مجلد `geniusbot-dashboard` نفسه.

أهم التعديلات:
- إضافة فواصل رأسية هادئة لكل الجداول مع إبراز عمود الإجراءات.
- تحسين ترويسة الجداول وHover للصفوف في جميع الصفحات.
- ألوان إجراءات موحدة: عرض/تعديل أزرق، تفعيل/تعطيل ذهبي، حذف أحمر، تحديث/إعادة تحميل أخضر.
- ألوان تشغيلية منفصلة لأزرار المواعيد: تأكيد/إكمال أخضر، تسجيل حضور أزرق، تغيير موعد بنفسجي، إلغاء أحمر.
- إصلاح النصوص العربية الناقصة مثل `UPDATED_AT` وتحويلها إلى `آخر تحديث`.
- تنسيق التواريخ الزمنية بصيغة محلية بدل ISO الخام في صفحات البيانات الأساسية.
- تعميم تفعيل/تعطيل السجلات التي تحتوي `is_active` بدل حصره بالغرف.
- تثبيت ترتيب صفحة تسجيل الدخول: العرض التعريفي يسارًا وبطاقة الدخول يمينًا على سطح المكتب العربي.
- استبدال شعار GeniusBot بالشعار المرفق مع إزالة زوايا الصورة المربعة وتحويله إلى PNG دائري شفاف.
- تحديث favicon وApple/PWA icons من الشعار الجديد.
- زيادة رقم cache-busting للشعار والأيقونات حتى لا يعرض المتصفح النسخة القديمة.

التحقق المنفذ:
- `tsc -b` PASS
- `eslint .` PASS
- `vite build` لم يكتمل داخل بيئة Linux بسبب native Rolldown binding الموجود في node_modules القادم من Windows؛ لا علاقة لذلك بالتعديلات المصدرية.

طريقة الاستخدام على جهاز Windows:
1. أوقف Vite.
2. استبدل مجلد `geniusbot-dashboard` الحالي بهذا المجلد مع الاحتفاظ بملف `.env` المحلي إن كان لديك إعدادات خاصة.
3. شغّل:
   `npm.cmd run dev -- --force`
4. افتح `http://localhost:5173/` ثم `Ctrl+F5`.
